Connect Kolli's Flow

This app uses Hugging Face Inference Providers for Qwen chat and AI image creation. Connect your own token on the server so it is not exposed in the public website.

1Open huggingface.co/settings/tokens and create an access token with Inference Providers permission.
2In this project folder, rename .env.example to .env and replace the sample value with your token: HF_TOKEN=hf_….
3Run npm install, then npm start. Refresh this page. For hosting, add HF_TOKEN as a server environment secret.

Chat and image creation will become available once the server is connected. The model/provider may require available credits.
